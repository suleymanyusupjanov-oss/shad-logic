Задача `$1`. Пожелания пользователя, если есть, — текст после номера: «$ARGUMENTS».

Основа: `tasks/$1/condition.md`, `tasks/$1/claude.md`, `tasks/$1/check.py`, а если сравнение уже было, то `tasks/$1/gemini.md` и результат /compare. Если сравнения не было, напомни об этом одной строкой и всё равно пиши.

1. Напиши развёрнутый ответ строго по разделу «Развёрнутый ответ» в AGENTS.md. Обычный текст без Markdown и LaTeX. Структура: обозначения и прочтение условия → решение по шагам с причинами → короткая проверка → последняя строка `Ответ: …`. Для открытой задачи — по разделу «Открытые задачи».
2. Проверь текст как строгий проверяющий, по чек-листу самопроверки из AGENTS.md. Каждое число сверь с выводом `check.py` (если нужно, запусти его снова). Исправь всё, что нашёл.
3. Сохрани итоговый текст в `tasks/$1/answer.md`.
4. В чат выведи:
   - одной строкой: что исправлено при самопроверке (или «замечаний нет»);
   - **весь текст ответа внутри одного блока ```text```**, чтобы его можно было скопировать кнопкой;
   - под блоком: «Дальше: во второй сессии Claude Code (проверяющий) → /review $1 + условие + этот текст, затем замечания сюда → /fix $1».
