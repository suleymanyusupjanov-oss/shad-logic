# shad-logic — часть 2 теста ШАД МТС

Две модели решают каждую задачу **независимо и одновременно**: Claude Code в облаке и Gemini в Antigravity на ноутбуке. Последнее слово — за проверкой кодом. Полный протокол лежит в `AGENTS.md`.

## Настройка (один раз)

**1. GitHub.** github.com → New repository → `shad-logic`, **Public**, без README → Create. Публичный — нормально: условия и решения из `tasks/` на GitHub не попадут, они в `.gitignore`. Потом в папке `obsidian2\shad-logic` открой терминал (ПКМ → «Открыть в терминале») и выполни:
```
mv _claude .claude
git init
git add .
git commit -m "shad-logic: протокол и инструменты"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/shad-logic.git
git push -u origin main
```
Первая команда переименовывает `_claude` в `.claude`: папку с точкой в начале имени Claude не может записать на твой компьютер сам, а Claude Code ищет команды именно в `.claude`. Если git попросит войти, откроется окно GitHub в браузере. Если не хочешь возиться руками, попроси агента в Antigravity выполнить эти команды за тебя.

**2. Claude Code (облако).** claude.ai/code → выбери репозиторий `shad-logic`. Если его нет в списке, дай приложению Claude доступ к нему в настройках GitHub. Новая сессия → напиши `/status`. Должна появиться таблица задач. При старте сессии z3 ставится сам.

**3. Antigravity.** Open Folder → `obsidian2\shad-logic`. В терминале Antigravity: `pip install z3-solver`. В чате набери `/solve`. Если такой команды нет, пиши: «Ты Gemini, работай по AGENTS.md. Задача 1: …».

## На тесте — порядок на каждую задачу (~50 мин)

1. Скопируй условие: текст плюс скрин, если есть картинка (Win+Shift+S).
2. **Claude Code** (новая сессия на каждую задачу): `/new 1 <условие>` → сверь формализацию с оригиналом → «ок» → `/solve 1`.
3. **Пока Claude решает → Antigravity** (новый чат на каждую задачу): `/solve`, затем то же условие и номер 1.
4. Скопируй блок ИТОГ из Antigravity → в Claude Code: `/compare 1 <ИТОГ>`.
5. Впиши в форму ШАД то, что стоит в строке «В форму».

- Пока модели решают задачу 1, можно уже запускать `/new 2` в соседней сессии.
- Если задача заняла 50 минут, а ответы так и не сошлись, впиши ответ, который подтверждает код. Переходи к следующей и вернись к этой в конце.
- В конце: `/status` в любой сессии. Все 4 задачи должны стоять с ✅ и быть вписаны в форму.

## Тренировка
`practice/tasks.md` — 4 задачи без ответов. Прогони 1–2 из них по этому порядку на время.
