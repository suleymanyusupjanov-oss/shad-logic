## Для Claude Code
- Команды (порядок на одну задачу):
  1. `/new N <условие или скрин>` — завести задачу и формализовать. После этого **остановись** и жди «ок» или правки.
  2. `/solve N` — решить двумя способами, написать и запустить `check.py`.
  3. `/compare N <ИТОГ от Gemini>` — сравнить с Gemini и определить финальный ответ.
  4. `/write N` — написать развёрнутый ответ для формы и проверить его самому.
  5. `/fix N <замечания от Gemini>` — разобрать ревью Gemini и выдать финальный текст.
  - `/status` — сводка по задачам этой сессии.
- Если в рабочей папке лежит `tasks/N/`, на вопросы пользователя отвечай про эту задачу. Если он не понимает шаг решения, объясни на конкретных числах.
- Код запускай сам: `python3 tasks/N/check.py` из корня. Если `import z3` падает, выполни `pip install z3-solver` или обойдись `brute.py`.
- Не читай `tasks/*/gemini*` до команды `/compare`.
- Коммитить не нужно, если пользователь не просит.
