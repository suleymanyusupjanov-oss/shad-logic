## Для Claude Code
- Команды:
  - `/new N <условие или скрин>` — завести задачу и формализовать. После этого **остановись** и жди «ок» или правки.
  - `/solve N` — решить двумя способами, написать и запустить `check.py`.
  - `/compare N <ИТОГ от Gemini>` — сравнить с Gemini и выдать ответ для формы.
  - `/status` — сводка по задачам 1–4.
- Если в рабочей папке лежит `tasks/N/`, на вопросы пользователя отвечай про эту задачу.
- Код запускай сам: `python3 tasks/N/check.py` из корня. Если `import z3` падает, выполни `pip install z3-solver` или обойдись `brute.py`.
- Не читай `tasks/*/gemini*` до команды `/compare`.
- Коммитить не нужно, если пользователь не просит.
