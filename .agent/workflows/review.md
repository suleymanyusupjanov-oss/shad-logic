---
description: Проверить развёрнутый ответ к задаче ШАД как строгий проверяющий (после того как задача решена)
---
1. Пользователь пришлёт номер задачи N, условие (или скажет, что оно уже есть в этом чате) и текст развёрнутого ответа.
2. Прочитай текст как строгий проверяющий на экзамене. Правила — раздел «Развёрнутый ответ» в AGENTS.md. Проверь:
   - отвечает ли текст ровно на заданный вопрос и в нужном виде;
   - обоснован ли каждый переход;
   - разобраны ли все случаи и доказано ли, что других вариантов нет, если это требуется;
   - верны ли числа. Пересчитай кодом: `tasks/N/gemini_check.py`, запуск `python -X utf8 tasks/N/gemini_check.py`;
   - нет ли противоречий с условием и непонятных мест;
   - нет ли Markdown, LaTeX, упоминаний нейросетей и файлов.
3. Не переписывай решение целиком.
4. Выведи список замечаний в формате:
```
РЕВЬЮ задача N
1. [критично | желательно] Где: … — Что не так: … — Как исправить: …
2. …
Итог: верно / есть ошибка / есть пробелы
```
Если замечаний нет, так и напиши: «Замечаний нет, решение верное и полное». Пользователь скопирует этот блок в Claude Code командой /fix.
